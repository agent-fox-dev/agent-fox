Command af is the agent-fox command line. Every command speaks one contract,
which internal/toolio implements: one JSON envelope on stdout, a fixed table
of statuses and exit codes, a resumable needs_human stop, a --dry-run that
cannot write to the forge, and a schema that af --schema prints. The commands
of the loops and the ring-1 commands are in internal/afcmd; the commands of the
agent-fox service client (login, workspace, jobs) are in this package, which
passes the process's arguments and streams to the shell they are registered on.
